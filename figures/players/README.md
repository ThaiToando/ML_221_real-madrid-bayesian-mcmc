Optional player photos for the profile cards (R22).

Add only photos your team has a licence for, named by Transfermarkt player id:
  figures/players/<player_id>.jpg   (or .png / .webp), square, at least 300 x 300 px

Record each licence (source, licence number or terms) in figures/players/LICENSES.md.
Find a player's id in data/processed/p3_rm_attackers.csv (column player_id).
Without a photo the card shows a plain silhouette. Nothing here is downloaded automatically.
Keep this folder out of any public repository if the licence does not allow publishing.
